## 3. how to run the Python programs

### A. number converter (`number_converter.py`)
this program takes a decimal number from the user and prints its binary and hexadecimal values

1. open terminal and go to the folder:
   ```bash
   cd mission-05-numbers-data
   ```
2. run the script:
   ```bash
   python3 number_converter.py
   ```
3. type a number like `25`:
   ```text
   enter a number: 25
   0b11001 0x19
   ```

### B. hello program (`hello.py`)
1. go to the mission 4 folder:
   ```bash
   cd mission-04-programs
   ```
2. run the script:
   ```bash
   python3 hello.py
   ```
   output: `Hello from Python`

## 4. summary of what i learned
- **IPOS and hardware:** how input (keyboard) goes through processing (CPU/RAM), shows as output (screen), and saves to storage (SSD)
- **terminal commands:** using `pwd`, `ls`, `mkdir`, `cp`, `mv`, and pipes to manage files easily
- **operating system:** how the OS manages RAM, CPU, running apps (processes), and file permissions
- **compilers and interpreters:** compilers turn whole code into binary before running; interpreters run code line by line
- **number systems:** converting between base 10 (decimal), base 2 (binary), and base 16 (hex), and how ASCII maps letters to numbers
- **Git and GitHub:** how commits save snapshots, branches let you work safely, and Pull Requests help teams collaborate
- **networks:** how DNS finds IP addresses, routers send packets, and browsers load pages from servers
