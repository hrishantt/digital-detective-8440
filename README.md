## Assignment Overview
The Digital Detective assignment is an independent practical investigation designed to explore fundamental computer systems concepts from the ground up. Through hands-on Terminal exploration, Python programming, and Git version control, this project examines:
1. Input-Process-Output-Storage (IPOS) workflows, hardware architecture, and computer-based everyday systems.
2. Command-line interface (CLI) file management, flags, Unix pipelines, and package managers.
3. Operating system architecture, system resource metrics, processes, file paths, and POSIX permissions.
4. Program execution models, contrasting ahead-of-time compilers with runtime interpreters.
5. Number representation (decimal, binary, hexadecimal), ASCII/Unicode character encoding, and a custom Python base converter.
6. Git version control branching, collaborative Pull Request workflows, and command reference.
7. Computer networking fundamentals (LAN, MAN, WAN, DNS, routers, packet switching, client-server models, and HTTP/TLS request lifecycles).
8. Comprehensive review, system report consolidation, and verification.

## My Learning
Through the Digital Detective investigations completed so far, key computational insights include:
1. **Hardware-Software Abstraction:** The IPOS model demonstrates how low-level physical keystrokes and electronic interrupts are handled by the OS kernel, mediated through memory buffers in RAM, and persisted to non-volatile SSD storage blocks.
2. **Terminal Control and Composability:** Command-line operations and Unix pipelines (`|`) provide a direct mechanism to query system metrics, inspect processes, and process data streams efficiently in memory without intermediate files.
3. **Data Uniformity Across Systems:** Underneath programming languages and character encodings, all data and instructions are fundamentally stored as binary bits (0s and 1s), efficiently expressed in hexadecimal for human inspection and translated seamlessly by compilers and interpreters.
